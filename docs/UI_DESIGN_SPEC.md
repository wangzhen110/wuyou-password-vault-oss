# 界面设计规范 - 极简密码本 V5.0

> 融合 UI UX Pro Max + ECC 规则，全面去AI味。
>
> **历史设计规范快照，不是现行 UI 规范或视觉验收记录。** 当前实现及验收状态以[项目状态与路线图](项目状态与路线图.md)为准；下方图标/布局清单不代表对应功能已实现。指纹图标仅是旧视觉清单中的图形条目，不代表当前支持生物识别解锁。

## 一、设计哲学

### 1.1 核心原则
- **极简**：每个页面只做一件事，不做多余装饰
- **克制**：只用1个主题色(#07C160)，其余黑白灰
- **真实**：参考Figma真实产品设计，不闭门造车
- **大号字**：PRD要求字号比常规大20%，按钮点击区域≥48px

### 1.2 反AI味规则（V5.0 - 来自UI UX Pro Max）
| 禁止 | 正确做法 |
|------|---------|
| emoji做图标 | 纯CSS/SVG图标 |
| 蓝紫色渐变按钮 | 纯色微信绿(#07C160)按钮 |
| 所有卡片一模一样 | 卡片内部元素间距可以不一致 |
| 文案居中对齐一切 | 标题左对齐，内容跟随 |
| 密密麻麻挤一起 | 页面边距32rpx，留白呼吸 |
| "暂无数据" | "还没有存密码，点这里开始" |
| 无按压反馈 | 所有可点击元素scale(0.98)+opacity |
| 低对比度文字 | 确保4.5:1对比度 |
| 随机间距 | 8rpx节奏系统 |

## 三、图标系统（V5.0 - 纯CSS）

### 规则
- **禁止emoji** - 遵循UI UX Pro Max: "No emojis used as icons (use SVG instead)"
- 所有图标用纯CSS实现（border-radius + border + transform）
- 图标尺寸统一：小20rpx，中32rpx，大44rpx

### 已实现的纯CSS图标
| 图标 | CSS实现 | 位置 |
|------|---------|------|
| 锁 | border-radius方块+半圆shackle | 解锁页/首页/TabBar |
| 眼睛 | border-radius椭圆+圆点 | 新增页/详情页 |
| 搜索 | border-radius圆+transform旋转线 | 首页 |
| 加号 | 两条十字线 | 首页FAB |
| 箭头 | border-right+border-bottom旋转 | 各页面 |
| 齿轮 | border-radius圆形+伪元素 | TabBar |
| 钥匙 | 线+圆 | 设置页 |
| 云 | border-radius圆组合 | 设置页 |
| 指纹 | border-radius椭圆 | 设置页旧图形清单；不代表生物识别解锁能力 |
| 消息 | border-radius圆角矩形+三角 | 设置页 |
| 耳机 | border-radius半圆 | 设置页 |
| 复制 | 双层border-radius矩形 | 详情页 |
| X清除 | 两条旋转线 | 首页搜索 |

## 四、触控反馈系统（V5.0 - 来自ECC）

### 规则
- **最小触控区域**: 48x48dp = 88rpx（Apple HIG标准）
- **间距**: 相邻触控元素≥8px/8dp（ECC touch-spacing规则）
- **按压反馈**: 所有可点击元素添加视觉反馈

### CSS类
- `.tappable` - 通用按压反馈 (opacity: 0.85, scale: 0.98, 150ms)
- `.card-press` - 卡片按压反馈 (shadow缩小, scale: 0.985, 150ms)
- `.btn-press` - 按钮按压反馈 (scale: 0.97, opacity: 0.9, 150ms)
- `.min-tap` - 最小触控区域 (88rpx x 88rpx)

## 六、无障碍规则（来自accessibility skill）

- 对比度：正文≥4.5:1，大字≥3:1
- 触控区域：≥48x48dp
- 动画时长：150-300ms，有意义的动效
- 支持prefers-reduced-motion
- 表单字段有标签和提示
- 禁用状态清晰可见
