# 用户隐私保护指引 · 后台填写文案（无忧密码本）

> 用途：微信小程序后台「账号设置 → 服务内容声明 → 用户隐私保护指引 → 去完善」逐项粘贴。
> 对应版本：4.0.97（代码实际调用：chooseAvatar、input type=nickname、wx.setClipboardData、wx.chooseMessageFile）
> 最后核对：2026-10-20

---

## 一、开发者处理的信息（逐项填写）

平台会根据代码接口调用自动生成必填项，以下三项均需勾选并填写用途：

### 1. 收集你的昵称、头像

**用途说明（可直接粘贴）：**

```
用于完善并展示你的账户资料：你可通过微信头像选择面板设置头像、通过键盘上方的"使用微信昵称"填入昵称，我们将昵称与头像随账户信息保存，用于在"我的账户"页面展示。
```

### 2. 读取你的剪切板

**用途说明（可直接粘贴）：**

```
仅在你主动点击"复制"时，将你选择的密码、邀请码或订单号写入系统剪贴板，便于你粘贴使用；本服务不会主动读取剪贴板中的其他内容。
```

> 注意：接口为 wx.setClipboardData（写入），官方归类在"读取你的剪切板"项下，如实声明即可。

### 3. 收集你选中的文件

**用途说明（可直接粘贴）：**

```
仅在你主动选择备份文件导入时读取该文件内容，用于恢复你的密码记录与账户数据；不会扫描或读取你设备中的其他文件。
```

## 二、开发者对信息的存储

```
密码记录在你的设备上完成加密后才上传至云端，服务器不保存记录明文，也无法还原；昵称、头像与订单信息存储于境内的腾讯云开发环境，保存期限为你的账号存续期间。你删除记录或停止使用本服务后，相应数据会随系统维护逐步清理。
```

---

## 三、信息的使用规则

```
1. 开发者将会在本指引所明示的用途内使用收集的信息。
2. 如开发者使用你的信息超出本指引目的或合理范围，开发者必须在变更使用目的或范围前，再次以弹窗方式告知并征得你的明示同意。
```

---

## 四、信息对外提供

```
1. 开发者承诺，不会主动共享或转让你的信息至任何第三方，如存在确需共享或转让时，开发者应当直接征得或确认第三方征得你的单独同意。
2. 开发者承诺，不会对外公开披露你的信息，如必须公开披露时，开发者应当向你告知公开披露的目的、披露信息的类型及可能涉及的信息，并征得你的单独同意。
```

```
关于你的个人信息，你可以通过以下方式与开发者联系，行使查阅、复制、更正、删除等法定权利。
```

## 提审前后顺序建议

1. 先在**入口1**（账号设置 → 服务内容声明 → 用户隐私保护指引）提交更新，等隐私协议**单独审核通过**；
2. 再到**管理 → 版本管理 → 4.0.97 → 提交审核**（此时平台比对隐私接口调用应无出入）；
3. 若提审时仍被拦截，按提示在**入口2**（提审信息填写页）补充，仅影响本次开发版本；
4. 审核通过后点**发布**，隐私协议随版本一同覆盖现网。
