# 4.3.0 云优先架构设计（2026-10-24 定稿）

> **方案来源**：用户提出「本地只存一个快照，获取密码时直接从服务器获取」。
> **状态**：**已定稿**，待实施。
> **前置条件**：数据已清零（2026-10-24），无历史迁移负担。

---

## 一、设计目标

```
本地：加密「列表快照」——只含列表渲染所需字段，用于首屏秒开
云端：完整密文——唯一权威数据
查看某条密码：实时从云端拉取，解密后只在内存显示
```

**核心约束**：**云端为准，快照只读**——本地永远不主动修改快照，只由同步流程覆盖。

---

## 二、数据分层

| 层 | 内容 | 位置 | 加密 |
|---|------|------|------|
| **完整记录** | 平台/账号/密码/备注/URL/标题/类型… | **仅云端** | 端侧加密后上传（密文） |
| **列表快照** | `id` / `title` / `platform` / `entryType` / `typeIcon` / `iconBg` / `seq` / `updatedAt` / `is_deleted` | **本地**（单个 key） | **整体加密**（复用 masterKey） |
| **解密后明文** | 快照明文 / 详情明文 | **仅内存**（页面 data） | — |
| **偏好类** | 主题、字号、排序、锁定时长、openid | 本地（明文） | 非敏感，保留 |

**快照不含**：`account` / `password` / `notes` / `url` / `alias`（这些只在详情里，从云端拉）。

---

## 三、关键流程

### 3.1 冷启动 / 解锁后

```
读本地加密快照 → 解密（需 masterKey）→ 渲染列表（秒开）
        ↓ 并行
后台触发 full_sync → 云端全量 → 重建快照 → 覆盖本地 → 刷新列表
```

**首屏用旧快照，同步完成后无缝替换**——用户无感知。

### 3.2 查看详情

```
点击列表项 → sync.get_entry(id) 从云端拉单条 → 解密 → 渲染详情
```

- **弱网/断网**：提示「查看详情需要联网」，列表仍可浏览
- **每次进入详情都拉**：保证数据最新

### 3.3 新增 / 编辑

```
写云端（加密上传）→ 成功 → 重新生成快照 → 覆盖本地 → 返回列表
```

**失败**：保留页面草稿 + 提示重试，不写本地快照。

### 3.4 删除

```
云端软删除（is_deleted）→ 成功 → 快照标记 is_deleted → 列表过滤
```

## 五、分阶段实施

| 阶段 | 内容 | 验收标准 | 风险 |
|------|------|---------|------|
| **P0** | `sync` 新增 `get_entry` action | 调用返回单条密文；越权访问他人 id 被拒 | 低（纯新增）|
| **P1** | `storage.js` 加快照层（加密读写 + 重建）| 单测：快照只含列表字段；无密码/账号字段 | 低（纯新增）|
| **P2** | `index` 改读快照 | 列表功能不变，179 测试全过 | 中 |
| **P3** | `detail` / `add` 改走 `get_entry` | 详情/编辑正常；断网有明确提示 | 中 |
| **P4** | `api-access` / `member` 适配 | 容量判断、API 列表正常 | 中 |
| **P5** | 移除本地完整记录写入路径 | 卸载重装后本地无完整记录 | 中 |

**P0-P1 纯新增，可先做且零风险**；P2-P5 逐页切换，每阶段跑 179 测试 + 真机验证。

## 六、取舍与代价（用户已确认）

| 取舍 | 决定 | 代价 |
|------|------|------|
| 断网可用性 | **列表可看，详情需联网** | 弱网下查详情要等 |
| 首屏速度 | **本地快照秒开** | 快照可能短暂滞后（同步后覆盖）|
| 安全性 | **本地只有加密快照**（无密码/账号）| 标题/平台加密后仍在本地（有主密码才能解）|
| 写入策略 | **先云端成功，再更新快照** | 点击后有短暂等待 |
| 一致性 | **云端为准，快照只读** | 双写冲突天然消除 |

## 七、ADR

**ADR-001：放弃「本地零数据」，采用「加密列表快照 + 详情实时拉」**

- **背景**：曾考虑完全云优先（本地不留任何密码数据）。评估后否决。
- **否决理由**：①断网完全不可用，对密码管理器是致命缺陷（地铁/电梯场景高频）；②首屏需每次拉全量（500 条上限），弱网体验差；③storage.js 29 处 + 6 页面核心路径全改，回归风险高；④安全收益有限——快照已加密，无主密码无法解开。
- **决策**：本地保留**加密列表快照**（无密码/账号/备注），详情每次从云端拉。
- **约束**：**云端为准，快照只读**——快照只由同步流程覆盖，本地不主动改，杜绝端侧数据打架。
