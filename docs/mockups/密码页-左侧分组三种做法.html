三种做法的取舍
  • G1 常驻窄侧栏：分组永远可见，切换最快；代价是右侧内容只剩 204px，长账号会被截断（如 me@corp.cn 后面看不见）。
  • G2 抽屉式：内容区全宽，长账号完整显示；切换分组要多一步（点开抽屉）。条目普遍较长时更稳。
  • G3 侧栏 + 组内折叠：最接近你原话"相同名字自动归类 + 可展开收缩"——但它多一层结构（组内再分组），层级变深，容易迷路。

需要你定的两件事（其余我按最优默认做）：
① 选 G1 / G2 / G3 哪种？我倾向 G2：窄屏上左侧栏会明显挤压账号显示。
② 「分组自定义」具体要做到什么程度？改名字 调顺序 隐藏分组 手动新建空分组 把某条移动到别组 —— 这几项工作量和风险差别很大，你勾需要的即可。
