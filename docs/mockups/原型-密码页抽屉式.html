  1. 搜索框始终显示在工具栏下方（44px），不再点图标展开
  2. 工具栏里的 🔍 图标已移除（避免重复）

关于「头像 + 容量」信息栏
  1. 保留：头像 / 昵称 / 会员徽章 / 已用·总容量 / 容量进度条，全部保留
  2. 压到 46px：容量文字与进度条改成右侧竖排（文字 10.5px + 3px 细条），不再占一整行
  3. 永不被遮挡：抽屉和遮罩都从信息栏下方 72px 处开始，头像和容量在抽屉展开时依然可见
  4. 随数据实时变：删一条记录，容量数字和进度条会立刻更新（可以试试点 ··· → 删除）
可以试这些操作
  1. 点左上角 ☰ → 抽屉滑出（280px，信息栏保持可见）
  2. 点某个分组 → 抽屉自动收回，列表切换
  3. 点分组标题（灰色条）→ 展开 / 收起
  4. 搜索框常驻，直接输入"微信"试试（右侧 ✕ 清空）
  5. 点行尾 ··· → 操作面板（复制密码等）
  6. 抽屉底部「编辑分组」→ 拖动排序、直接改名、开关隐藏
  7. 抽屉底部「新建分组」→ 手动建一个空分组
  8. 点遮罩任意处 → 关闭抽屉
「全部」和分组的关系
按你最早说的：「全部」= 平铺，按录入时间倒序（最新在最上），不折叠； 选具体平台才显示该平台的条目、并按账号折叠。

这样两个视图各有用途：「全部」用来"我最近加了什么"，分组用来"找某个平台"。
当前实现的取舍
  1. 搜索时强制展开所有命中分组——否则搜到了却看不见
  2. 隐藏的分组不出现在抽屉里，但数据仍在（可在编辑页恢复）
  3. 改名/排序/隐藏只存本地（原型用内存），真实实现需存 storage 并考虑是否同步
  4. 「把某条记录移到别组」没做——它会破坏"同名自动归类"，需要单独设计
