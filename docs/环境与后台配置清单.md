## 二、云函数环境变量

> 变量按函数**独立配置**（`vpay` 配了不代表 `vpayCallback` 有）。依据：各函数 `process.env.*` 静态扫描。

| 函数 | 必需变量 |
|------|---------|
| `vpay` | `VPAY_APP_KEY`、`VPAY_APP_SECRET`、`WX_APP_ID`、`VPAY_ENV`（=0 现网） |
| `vpayCallback` | 上述 4 个 **+** `VPAY_TOKEN`、`VPAY_AES_KEY`（安全模式验签解密用） |
| `ensureCollections` | `ADMIN_OPENIDS` |
| 其他（login/invite/sync/pay/apiAuth/openapi） | 无环境变量依赖 |

**取值来源**：`VPAY_APP_KEY` / `VPAY_APP_SECRET` / `WX_APP_ID` 来自 MP 后台虚拟支付「基本配置」；`VPAY_TOKEN` / `VPAY_AES_KEY` 来自虚拟支付消息推送配置（安全模式）；`VPAY_ENV=0` 表示现网（沙箱为 1）。

## 七、部署顺序（复刻时按此执行）

1. 开通云开发 → 创建环境 → 记录环境 ID
2. 改 `app.js` 的 `env` 为你的环境 ID
3. 部署 10 个云函数（推荐 MCP `updateFunctionCode`，CLI 曾出现挂死）
4. 配置云函数环境变量（第二节）
5. 开通虚拟支付 → 拿 OfferID/AppKey → 改代码 `OFFER_ID` 与 `VPAY_APP_KEY`
6. 创建并**发布**两个道具（等同步）
7. 配简称 → 开苹果 IAP
8. 配 HTTP 路由 `/v1`、`/vpay`
9. 配隐私保护指引 → 提审

> 每步的验收判据见 `docs/复刻验收清单.md`。
