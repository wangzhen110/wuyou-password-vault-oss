# 历史数据库初始化草案

> **历史快照，不是当前数据库契约。** 本文源自早期设计，包含与现行加密封套不符的字段和集合假设。当前状态见[项目状态与路线图](项目状态与路线图.md)，当前操作说明见[根目录云数据库集合说明](../CLOUD_DATABASE_SETUP.md)。

早期草案曾假设 `passwords` 中存在 `username_enc`、`password_enc`、`notes_enc` 等字段，并把 `categories`、`settings` 作为独立业务数据集合。这些字段表不能代表当前云端记录结构：当前同步云函数要求版本化封套字段，并拒绝上传明文敏感字段。

早期文档中的 `deleted_at` 与“定时清理软删除记录”也不是当前实现承诺。当前删除使用 `is_deleted` 软删除标记；源码没有硬删除或定时清理实现。软删除不表示云端历史数据或备份已物理擦除。

保留此文件仅用于识别旧方案与历史数据。部署前请以当前源码及根目录数据库说明核对集合、权限和字段；不要照旧字段表建立索引或据此判断生产数据已迁移。
