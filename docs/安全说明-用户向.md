# 安全说明

> 面向使用者与想验证的人。本文只描述**当前源码事实**，不代表第三方独立审计结论。
> 技术参数以 `miniprogram/utils/crypto.js` 与 `cloudfunctions/sync/index.js` 为准；项目整体状态见[项目状态与路线图](./项目状态与路线图.md)。

---

## 一句话

**你只记一个主密码。加密在你的手机上完成，服务器上存的是一堆打不开的乱码。**

---

## 1. 你的密码经历了什么

1. **主密码从不发送**：解锁时，主密码只在你的设备上参与密钥派生，永远不会作为数据上传（上云的是派生出的校验值，不是主密码本身）。
2. **每条记录单独加密**：同一条记录重新保存一次，密文也会变（每条独立 IV 与独立 MAC）。
3. **云端只收信封**：服务端只接受 `id / crypto_version / iv / ciphertext / mac / salt / 时间戳 / 删除标记` 这几类字段。
4. **明文敏感字段上不去**：`account`、`password`、`notes` 这类字段如果出现在上传数据里，**服务端直接拒绝**。
5. **连标题都是加密的**：标题不在服务端允许的字段里，它被包在密文内部。

---

## 2. 我们防什么

| 威胁 | 结果 |
|---|---|
| 服务器被拖库 | 攻击者拿到的是密文 + 盐 + 校验值，没有明文 |
| 云端运维/内部人员翻数据 | 看到的是乱码，无法还原内容 |
| 网络传输被截获 | 传输的是密文，明文不出设备 |
| 备份文件泄露 | 备份同样使用你主密码派生的密钥加密 |
| 取件链接被转发/长期滞留 | 链接一次性：成功下载一次即失效；密码错 5 次即作废；10 分钟到期。三种失效都会**立即删除云端的备份文件**，不留残件 |

---

## 3. 我们不防什么（这一段请务必读完）

安全说明只列“能防什么”是不诚实的。以下是**真实边界**：

| 边界 | 说明 |
|---|---|
| **弱主密码** | 如果服务器被拖库，攻击者可以离线暴力猜你的主密码。迭代 60 万次只是**提高成本**，救不了 `123456`。因此产品强制：8–11 位必须同时含字母和数字 |
| **设备被控制** | 手机被植入木马或被远控，解锁后的明文会被读走。端侧加密防不住端侧被攻破 |
| **忘记主密码** | **无法找回**。这是设计而非缺陷——如果我们能帮你找回，就说明我们能解密 |
| **元数据可见** | 记录条数、创建/修改时间、是否删除、容量占用，这些是明文（用于同步与配额统计），内容本身不可见 |

## 4. 你可以自己验证（三步，不需要看源码）

> 这一节是本文的重点。任何“我们很安全”的说法，都不如你自己动手验证一次。

### 验证一：上传的数据里有没有明文

1. 打开微信开发者工具，导入本项目，打开 **Network** 面板（或手机端配置代理抓包）
2. 解锁 → 新增一条测试密码，账号填 `test@example.com`，密码填 `abcdefg12345`
3. 查看同步请求的 **Payload / Request Body**

**预期**：你能看到 `ciphertext`、`iv`、`mac`，**看不到** `test@example.com` 和 `abcdefg12345`。

### 验证二：解密是不是在你手机上做的

1. 正常解锁，进入列表
2. **断网**（飞行模式）
3. 打开任意一条已有密码

**预期**：仍然能看到明文。因为你看到的内容来自本地解密，不依赖服务器。

> 适用范围：当前 4.3.x 版本（本地保存加密记录）。若将来启用「云优先」架构，此行为会随之变化，届时本文同步更新。

### 验证三：主密码有没有被发出去

1. 退出锁定，故意输错主密码
2. 抓包观察请求

**预期**：被拒绝，且请求里**找不到你的主密码**。上传/下载的是用主密码派生的**校验值**（verifier），比对在你的设备上完成——所以主密码本身始终没有离开手机。

> 注意区分：主密码不上传 ≠ 校验值敏感。校验值可以被拿到，这正是「弱主密码可被离线爆破」的原因——见第 3 节。

## 5. 技术参数（给愿意深看的）

| 项 | 值 |
|---|---|
| 格式版本 | `crypto_version: 1` |
| 密钥派生 | PBKDF2-HMAC-SHA256，**600,000 次**，**16 字节**随机盐 |
| 派生结果 | **64 字节**，拆分为 AES 密钥与 MAC 密钥 |
| 正文加密 | AES-256-CBC |
| 完整性 | HMAC-SHA256，覆盖封套元数据与密文；**解密前先验 MAC** |
| 随机源 | 不可用时**失败关闭**（fail-closed），不降级 |
| 旧格式兼容 | SHA-256 + 500 次迭代，**仅用于迁移**，不是新格式的 KDF |

加密在端侧完成，云端不得出现明文或可解密材料（主密码、派生密钥永不上云）。
